# TOKO SAKALA — Cek Sisa Sekaligus Workflow Pack v1.0

Paket ini ditujukan untuk diterapkan **ke repository yang sudah ada** melalui Google AI Studio. Prompt meminta agent memeriksa file terkini dan memperbarui layar yang tepat tanpa membuat proyek baru atau menimpa pekerjaan UI yang sudah ada.

1. Buka aplikasi yang sekarang di Google AI Studio Build.
2. Lampirkan foto kertas sebagai referensi jika diminta.
3. Salin seluruh isi `TOKO_SAKALA_WORKFLOW_REFINE_PROMPT_v1.0.md` ke chat Build.
4. Tinjau diff sebelum menyetujui perubahan, lalu jalankan tes dan build di runtime.
5. Setelah hasil diperiksa, commit dan Push origin melalui GitHub Desktop.

Subtotal contoh Rp524.000 adalah nilai stok sisa menurut harga jual, bukan modal dan bukan keuntungan. Penyimpanan yang hanya berada di state/browser bukan data transaksi produksi.
