# UX Gate — required before persistence is enabled

- [ ] Main screen shows no more than five key numbers/statuses.
- [ ] One primary action is obvious.
- [ ] No financial accounting jargon on level 1/2.
- [ ] All forms use Indonesian labels and direct examples.
- [ ] Only ask one clarifying question at a time, and only when the system cannot infer safely.
- [ ] Preview is labelled “belum disimpan”; no separate “Hitung” button.
- [ ] Every save confirmation names the changed item and important result.
- [ ] Failed/offline write never claims success; draft stays visible; no hidden offline queue.
- [ ] Unknown values have explicit certainty labels.
- [ ] Empty screens do not invent sample transactions.
- [ ] Status uses text/icon as well as color.
- [ ] User can access “Kenapa?” and “Lihat perhitungan” details without making the default screen busier.
