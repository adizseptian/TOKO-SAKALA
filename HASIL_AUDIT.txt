- Temuan Awal: Potensi kebingungan pengguna apakah tombol kalkulasi belanja atau cek sisa stok langsung menyimpan data ke disk atau Google Drive.
- Hasil Verifikasi Faktual:
  1. Form Catat Belanja menjalankan fungsi kalkulasi murni calculatePurchasePreview yang mengembalikan subtotal, packQuantity, dan totalPieces. Tombol "Lanjut ke pratinjau" hanya menampilkan toast kalkulasi tanpa melakukan komit data.

  3. Form Setoran Karyawan menghitung selisih nominal (discrepancy = receivedAmount - expectedAmount) secara reaktif murni di sisi memori UI.
- Tindakan Remediasi: Menjaga isolasi kalkulasi pratinjau dan memastikan penulisan ke Google Drive hanya terjadi ketika pengguna secara sadar menekan aksi cadangkan / sinkronisasi.

### 3. ARSITEKTUR INTEGRASI GOOGLE IDENTITY SERVICES (GIS) & GOOGLE DRIVE

src/storage/
├── types.ts              # Zod schema, types, validasi integer Rupiah & fisik
├── checksum.ts           # SHA-256 canonical hashing deterministik
├── storageAdapter.ts     # Interface StorageAdapter & default state payload
├── mockStorageAdapter.ts # In-memory adapter (khusus unit testing simulasi)
├── googleAuth.ts         # Google Identity Services (GIS) Token Client & lifecycle
├── googleDriveAdapter.ts # Google Drive REST API v3 client, live checks, safe restore
└── index.ts              # Export modul terpadu

1. Alur Otorisasi Client-Side (GIS Token Client):
   - Script https://accounts.google.com/gsi/client dimuat secara asinkron di index.html dan dinamis di googleAuth.ts.
   - Menggunakan google.accounts.oauth2.initTokenClient dengan skop minimum https://www.googleapis.com/auth/drive.file.
   - Pop-up otorisasi meminta persetujuan pemilik akun adizseptian@gmail.com.
2. Siklus Hidup Token & Keamanan:
   - Access token TIDAK PERNAH disimpan di localStorage atau sessionStorage.
   - Disimpan murni di variabel memori GoogleAuthService.
   - Kedaluwarsa dihitung dari expires_in dengan batas pengaman 60 detik.
   - Jika token kedaluwarsa atau server merespons 401, status otomatis berubah menjadi EXPIRED dan tombol UI berubah menjadi "Otorisasi Ulang Akun Google".
3. Konfigurasi Client ID:
   - Dibaca dari import.meta.env.VITE_GOOGLE_CLIENT_ID.
   - Jika belum diisi, UI Pengaturan menyediakan dialog modal untuk memasukkan Client ID secara langsung di sesi peramban tanpa perlu rebuild kode.
   - Peniadaan Client Secret (aman 100% untuk client-side browser dan repositori publik).
4. Proteksi Integritas Data & Snapshot Keselamatan:
   - Checksum SHA-256 deterministik memverifikasi keutuhan payload file toko-sakala-data.json.
   - Sebelum pemulihan data (restoreBackup) dieksekusi menimpa data aktif, adapter otomatis mengambil cadangan pengaman (Safety snapshot before restore).

### 6. DAFTAR TINDAKAN MANUAL YANG BENAR-BENAR MASIH DIPERLUKAN PEMILIK

Karena aplikasi ini berjalan 100% di sisi peramban pengguna tanpa server backend berbayar (memenuhi aturan anggaran Rp0), Google Cloud Platform mewajibkan pemilik akun (adizseptian@gmail.com) untuk mendaftarkan Client ID dan domain hosting aplikasi secara sah:

1. Buka Google Cloud Console:
   - Masuk ke Google Cloud Console Credentials (https://console.cloud.google.com/apis/credentials) menggunakan akun adizseptian@gmail.com.
2. Aktifkan Google Drive API:
   - Masuk ke menu APIs & Services > Library.
   - Cari Google Drive API dan klik Enable.
3. Buat OAuth 2.0 Client ID:
   - Pada menu Credentials, klik Create Credentials > OAuth client ID.
   - Pilih Application type: Web application.
   - Beri nama (misal: TOKO SAKALA Web Client).
4. Daftarkan Authorized JavaScript Origins:
   - Pada kolom Authorized JavaScript origins, tambahkan origin hosting Anda:
     - URL Pengembangan Lokal: http://localhost:3000
     - URL Preview AI Studio: salin langsung dari tombol "Salin" di modal Pengaturan aplikasi TOKO SAKALA (misal: https://ais-dev-...run.app).
   - Catatan: Tidak memerlukan Authorized redirect URIs karena alur GIS menggunakan token pop-up.
5. Konfigurasikan Client ID di TOKO SAKALA:
   - Salin Client ID yang diberikan oleh Google (format: xxxxxx.apps.googleusercontent.com).
   - Opsi A (Melalui Antarmuka): Buka TOKO SAKALA > Menu Lainnya > Pengaturan & Tema > klik Atur Client ID > tempel Client ID > klik Simpan Client ID.
   - Opsi B (Melalui File .env): Buka file .env di komputer Anda, isi VITE_GOOGLE_CLIENT_ID=xxxxxx.apps.googleusercontent.com.
6. Uji Koneksi Google Drive Nyata:
   - Klik tombol Hubungkan Akun Google (Login).
   - Pop-up Google akan muncul, pilih akun adizseptian@gmail.com, dan berikan izin akses file.
   - Setelah terhubung, klik Tes Sambungan untuk memverifikasi kapasitas kuota Drive Anda dan lakukan Cadangkan Manual ke Google Drive.
